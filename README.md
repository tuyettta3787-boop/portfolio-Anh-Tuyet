# Portfolio – Trần Thị Ánh Tuyết

Website Portfolio / CV số cá nhân – bài tập môn **Lập trình Web** (Trường ĐH Giao thông vận tải TP.HCM).
Ý tưởng thiết kế: **cuốn album ảnh & phim** – mỗi mục là một trang album, học vấn là dải phim, dự án là các khung slide, liên hệ là bưu thiếp.

## Công nghệ
HTML5 · CSS3 (Flexbox, Grid, animation, mask) · JavaScript thuần · Three.js (sticker 3D trên mặt bàn)

## Cấu trúc
```
index.html        trang chính
css/album.css     toàn bộ giao diện
js/album.js       tương tác (mở bìa, menu, lọc dự án, cửa sổ chi tiết, thanh kỹ năng, form)
js/bg3d.js        sticker 3D;  js/vendor/three.min.js
images/           hình ảnh (images/projects/ là ảnh dự án)
files/            CV-Tran-Thi-Anh-Tuyet.pdf
```

## Chạy
Mở `index.html` bằng trình duyệt (không cần cài đặt).
